# OpenECU

Open-source ECU calibration and diagnostic platform.

## Objectives

- ECU identification
- Firmware analysis
- A2L/DAMOS definition import and validation
- 2D/3D calibration editing
- Reproducible calibration solutions
- Independent ECU communication engine
- Optional local AI assistance

## Architecture

- Rust: core engines
- React / TypeScript: user interface
- Tauri: desktop application
- Windows and Linux support
